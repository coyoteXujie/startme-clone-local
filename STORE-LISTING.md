# StartMe - Custom New Tab

## English Description (Chrome Web Store - Detailed Description)

Transform your new tab page into a beautiful, productive dashboard with StartMe.

StartMe is a feature-rich Chrome extension that replaces your default new tab with a fully customizable start page. Organize your digital life with multi-tab workspaces, bookmarks, RSS feeds, tasks, weather, and more — all with stunning glassmorphism design.

### Key Features

**Multi-Tab Workspaces**
Create separate tabs for different contexts — Work, Study, Entertainment — each with its own set of widgets. Switch between them instantly.

**Smart Bookmarks**
Save your favorite links in two view modes:
- Cloud View: Elegant pill-shaped layout inspired by Start.me
- Grid View: Clean card-based layout with auto-fetched favicons

**RSS Reader**
Subscribe to any RSS feed and stay updated with the latest news from your favorite sources. Manage multiple feeds with pagination support.

**Task Manager**
A minimal todo list to keep you focused on what matters. Add, complete, and delete tasks with a single click.

**Weather Widget**
Real-time weather data powered by Open-Meteo (free, no API key needed). Supports multiple cities with 3-day forecasts.

**Pomodoro Timer**
Built-in focus timer with 25-minute work sessions and 5-minute breaks. Stay productive with visual progress tracking.

**Search Engine**
Switch between Baidu, Bing, and Google instantly. Add your own custom search engines.

**Custom Backgrounds**
Upload your own image or set a URL as your background. Create a workspace that feels uniquely yours.

### Privacy First

All data is stored locally on your device using chrome.storage.local. No accounts, no cloud servers, no tracking. Your data stays yours.

Export and import your data as JSON for easy backup and migration.

### Design

- Glassmorphism UI with frosted glass effects
- Smooth animations and micro-interactions
- Touch-friendly 44px minimum tap targets
- Responsive layout that adapts to any screen size
- Beautiful teal-green color system using modern OKLCH colorspace

### Tech Stack

Built with React 18, TypeScript, Vite 5, and Chrome Manifest V3.

## 中文详细描述（Chrome Web Store）

将你的新标签页变成一个美观高效的工作台。

StartMe 是一款功能丰富的 Chrome 扩展，用完全可自定义的起始页替换默认新标签页。通过多标签工作区、书签、RSS 订阅、任务清单、天气、番茄钟等功能，配合惊艳的毛玻璃设计风格，让你的数字生活井井有条。

### 核心功能

**多标签工作区**
为不同场景创建独立标签页——工作、学习、娱乐——每个标签页拥有自己的小组件集合，一键切换。

**智能书签**
两种展示模式：
- 云图模式：受 Start.me 启发的优雅药丸形状布局
- 网格模式：整洁的卡片式布局，自动获取网站图标

**RSS 阅读器**
订阅任意 RSS 源，实时获取最新资讯。支持多源管理和分页浏览。

**任务清单**
极简待办事项管理，让你专注当下。单击即可添加、完成或删除任务。

**天气组件**
基于 Open-Meteo API 的实时天气数据（免费，无需 API Key）。支持多城市切换和 3 天天气预报。

**番茄钟**
内置专注计时器，25 分钟工作 + 5 分钟休息模式，可视化进度追踪。

**搜索引擎**
在百度、Bing、Google 之间快速切换，支持添加自定义搜索引擎。

**自定义背景**
上传本地图片或输入 URL 作为背景，打造独一无二的工作空间。

### 隐私优先

所有数据通过 chrome.storage.local 存储在本地设备上。无需账号、无云端服务器、无追踪行为。数据完全属于你。

支持一键导出/导入 JSON 备份。

### 设计特点

- Glassmorphism 毛玻璃 UI，清爽通透
- 流畅动画与微交互反馈
- 所有按钮符合 44px 最小触控标准
- 响应式布局，适配任意屏幕尺寸
- 采用现代 OKLCH 色彩空间的青绿色主题
