Privacy Policy

StartMe - Custom New Tab (Chrome Extension)

Summary: StartMe is designed with privacy as a core principle. All user data is stored locally on your device. We do not collect, transmit, or store any personal data on remote servers.

1. Information We Collect

StartMe does NOT collect any personal data.

This extension operates entirely locally on your browser. Here is what is stored and where:

Data Type Storage Location Purpose
Bookmarks / Links chrome.storage.local Saved bookmarks displayed in widget
RSS Feed URLs chrome.storage.local List of subscribed RSS sources
Tasks / To-dos chrome.storage.local User task list
Weather Cities chrome.storage.local Cities for weather display
Tab Configuration chrome.storage.local Tab names, widget layout, settings
Background Image chrome.storage.local Custom background image (base64 or URL)
Search Engine Preference chrome.storage.local Selected search engine

2. Permissions Used & Why

StartMe requests the following permissions:

storage

Used to save all your data (bookmarks, tasks, tabs, settings, etc.) locally on your device via chrome.storage.local. No data is sent to any external server.

StartMe does not request browser geolocation permission. Weather cities are entered manually by the user.

host_permissions (Network Access)

The extension connects to the following services for specific features:

Domain Purpose Data Sent
api.open-meteo.com Weather data (temperature, forecast) Latitude & longitude coordinates only
geocoding-api.open-meteo.com Look up coordinates for manually entered city names City name
api.rss2json.com Convert RSS feeds to JSON format RSS feed URL
icon.horse Fetch website favicon icons Website domain name
favicon.im Fallback favicon service Website domain name

No authentication tokens, passwords, or personal identifiers are ever transmitted.

3. Third-Party Services

StartMe integrates with the following third-party services:

Open-Meteo (Weather)

  • Service: Free, open-source weather API
  • Data: Receives manually entered city names for lookup and geographic coordinates for forecasts
  • Privacy Policy: open-meteo.com/en/docs#privacy
  • No registration or API key required

rss2json.com (RSS Parsing)

  • Service: Converts XML RSS feeds to readable JSON
  • Data: Receives the RSS feed URL you add
  • Privacy Policy: Refer to their website terms
  • Note: Free tier has monthly request limits

icon.horse / favicon.im (Favicons)

  • Service: Website favicon retrieval
  • Data: Receives domain names of bookmarked sites
  • Purpose: Display site icons next to bookmarks

4. Data Storage & Security

  • All user data is stored in chrome.storage.local, which is encrypted by Chrome's storage mechanism
  • Dashboard data is never uploaded to StartMe servers; feature-specific requests are sent only to the services listed above
  • The Export feature creates a downloadable JSON file — you control where it is saved
  • Uninstalling the extension permanently deletes all stored data
  • No cookies, no tracking scripts, no analytics

5. Children's Privacy

StartMe does not knowingly collect any personal information from children under 13 years of age. The extension does not have features that target or collect data specifically from children.

6. Changes to This Policy

If we update this privacy policy, we will update the "Last updated" date below and revise this document in the extension's repository.
